Welcome to the TikFinity dock
  1. Open TikFinity Desktop and go live on TikTok — the dot in the corner turns green and events stream in.
  2. To send chat from this dock, run SETUP.bat once, then point TikFinity at it: Setup → Streamer.bot Connection → 127.0.0.1 port 8080, and tick “Allow Streamer.bot to push messages to TikFinity” under Chatbot.
  3. Everything else is automatic. Settings (⋮) → Updates keeps the dock itself current.
